## Deploy to GitHub + Vercel
1. Upload the contents of this folder to the root of your GitHub repository.
2. Commit the changes to `main`.
3. Vercel will automatically create a new deployment if the repository is already connected.
4. No build command is required because this is a static HTML/CSS/JS website.
5. Later, add your Namecheap domain in Vercel > Domains.
